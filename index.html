Not sure what to buy?

Choosing a server

  • Tower — small business or branch office; file sharing and light apps. Easy to upgrade and cool.
  • Rack — SME data center; the balanced choice for compute, storage and networking.
  • Blade — larger enterprise with limited floor space and many servers for demanding applications.

Choosing storage

  • NAS — file sharing, archives, CCTV and media. Simple and cost-effective.
  • SAN — mission-critical databases and performance-sensitive workloads.
  • Unified — both file and block data on a single platform.

HCI or three-tier?

  • Choose HCI if you run many virtual machines, want one console instead of silos, or are building a private cloud, VDI or a remote-office site.
  • Choose three-tier if you need to scale compute and storage independently or support physical servers too.
